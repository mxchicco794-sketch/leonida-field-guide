# Leonida Field Guide

Create a new premium mobile-first application called LEONIDA COMPANION.



This is a serious GTA 6 fan companion application, not a generic landing page.



Build the initial application using React, TypeScript and Vite.



DESIGN:



- Premium dark interface.

- Black and charcoal backgrounds.

- Subtle red accents inspired by GTA VI.

- Modern, polished mobile interface.

- Professional navigation and smooth animations.



MAIN NAVIGATION:



- Map

- Discover

- Collectibles

- Favorites

- Profile



MAP:

Prepare an interactive Leonida map using Leaflet.

The map must use the actual public map data from:

https://fbritoferreira.github.io/gta6/



DATA:

Read the documentation from:

https://github.com/fbritoferreira/gta6



Use its published JSON data and map tiles. Preserve CC BY 4.0 attribution.



IMPORTANT:

Do not invent locations, collectibles or map coordinates.

Do not use placeholder map data.

Build a scalable architecture that supports automatic data synchronization, offline caching and locally saved user progress.



First create the application foundation and a beautiful, functional mobile dashboard. Do not pretend features are implemented if they are not.



Make the interface feel like a professional gaming companion app.
